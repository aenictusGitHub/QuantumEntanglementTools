# Induced Schatten norm lower bounds

For a linear map \(\Phi:\mathbb{C}^{d_{\rm in}\times d_{\rm in}}
\rightarrow\mathbb{C}^{d_{\rm out}\times d_{\rm out}}\), the induced Schatten
norm is

```math
\lVert\Phi\rVert_{p\rightarrow q}
=
\sup_{X\ne 0}
\frac{\lVert\Phi(X)\rVert_q}{\lVert X\rVert_p}.
```

`induced_schatten_lower_bound` returns a complete
`InducedSchattenNormResult`, not a bare scalar. The `2 -> 2` branch is exact:
under column-major vectorization it is the largest singular value of the
map's transfer matrix. Every other branch follows the alternating
Hölder-equality iteration in the pinned QETLAB routine and remains a
**witnessed lower bound**, even if the objective change converges.

```jldoctest induced-schatten
julia> using QuantumEntanglementTools, LinearAlgebra, Random

julia> identity_map = KrausRepresentation([Matrix{Float64}(I, 2, 2)]);

julia> exact = induced_schatten_lower_bound(
           MersenneTwister(1), identity_map, 2
       );

julia> (exact.value, exact.bound_kind, exact.status)
(1.0, :exact, :exact)

julia> lower = induced_schatten_lower_bound(
           MersenneTwister(2),
           identity_map,
           3;
           q=2,
           initial_matrix=[1.0 2.0; -3.0 4.0],
           max_iterations=100,
       );

julia> (lower.bound_kind, lower.status, lower.witness_input_norm ≈ 1)
(:lower_bound, :converged_lower_bound, true)

julia> lower.value ≈ 2.0^(1 / 6)
true
```

For the identity map on \(2\times2\) matrices, the displayed lower-bound
value is independently known from the vector norm relation between singular
values. The example therefore tests the implementation without relabeling the
general iterative algorithm as an exact solver.

## Result and failure semantics

The result records:

- `value`, `bound_kind`, `exact`, and `status`;
- the normalized matrix `witness`;
- independently computed input/output norms and their residuals;
- the last objective-change residual and complete `objective_history`;
- completed iterations and deterministic work accounting;
- the configured iteration and work limits.

`status=:converged_lower_bound` means only that the absolute objective change
met `tolerance`. `:iteration_limit` and `:work_limit` retain the best witness
already found. `:stationary_zero` means the chosen start reached a zero output
or dual gradient; it is not a proof that the map itself has zero norm.

An explicit `rng::AbstractRNG` is mandatory. The exact branch and calls with
`initial_matrix` do not consume it. A generated start draws only from the
supplied RNG, never from Julia's global stream.

## Representation and resource policy

The native function accepts every package `AbstractMapRepresentation` between
square input and output matrix algebras, including general two-sided
operator-sum maps. A tuple or vector of Kraus matrices is a convenience input.

The alternating method performs dense SVDs of one input-sized and one
output-sized matrix on each update. Sparse work matrices therefore require
`allow_densify=true`. `max_dense_entries` checks each planned dense matrix and
the exact transfer matrix before conversion. `max_iterations` and `max_work`
are deterministic; no wall-clock-derived stopping or sample count is used.
`nothing` explicitly disables the dense-entry or work guard.

The dependency-free spectral path accepts `Float32`, `Float64`,
`ComplexF32`, and `ComplexF64` map data without changing precision. It does
not normalize map data, symmetrize matrices, clip singular values, or repair
an invalid start.

## QETLAB compatibility

`MATLABCompat.InducedSchattenNorm` preserves the positional
`(PHI, P, Q, DIM, TOL, X0)` order, the case-insensitive `"fro"` alias, and a
scalar random-start sentinel. It adds a mandatory leading RNG and returns the
same structured result. Numeric Choi matrices, Kraus collections, and
one/two-column factor-cell matrices are converted through the tested map
model. Invalid `DIM` or non-scalar malformed `X0` data raise rather than
silently switching to a different computation.

This wrapper intentionally restores a documented but unreachable pinned
route. `InducedSchattenNorm.m` forwards `DIM`, `TOL`, and `X0` to helper
functions that accept only `DIM`, so a pinned call that actually supplies
`TOL` or `X0` fails before the iteration. The Julia entry points validate and
use both values.

A source-free fixture generated by Octave 11.3.0 from the pinned revision
records eight seeded identity, diagonal-conjugation, and amplitude-damping
values/witnesses. Its 24 comparator assertions pass on Julia 1.12 and 1.10
with SHA-256
`3004ab728e151f70be75e1c0eeed7e8236b5fbcca29dc8261cc7dd97c5332905`.
The iterative fixtures are lower-bound evidence only. MATLAB was not run.
