# Support

QuantumEntanglementTools.jl is experimental software. For usage problems, open
a bug report with a minimal Julia example, exact package commit, subsystem
dimensions, numeric/storage type, tolerances, and backend status. For a
suspected mathematical error or false certificate, use the dedicated
correctness report so the convention and independent evidence are explicit.

For security vulnerabilities, follow the current confidential channel in
[`SECURITY.md`](SECURITY.md); use GitHub private vulnerability reporting only
after that repository feature is enabled. Never open a normal issue for an
unpatched vulnerability. Do not attach credentials, private datasets,
copyrighted source dumps, or proprietary solver files to any report.

The package is independent and is not an official QETLAB project. Questions
about upstream MATLAB behavior should state the exact QETLAB revision and
whether MATLAB or Octave was actually run.
